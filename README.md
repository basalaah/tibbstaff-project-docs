# tibbstaff.com — Medical Recruitment Platform

A cross-platform medical recruitment platform designed to connect healthcare professionals with hiring institutions in Yemen.

**Status:** Live — early-stage adoption  
**Application:** Flutter Web / Progressive Web App (PWA)  
**Original Platform:** Flutter mobile application  
**Source Code:** Private  
**Website:** [tibbstaff.com](https://tibbstaff.com)

## Overview

tibbstaff.com is a medical recruitment platform developed collaboratively by two developers. It aims to help healthcare professionals discover employment opportunities and enable hiring institutions to manage recruitment activities.

The project began as a business idea, but we eventually decided to make the platform free to use. Development initially focused on a Flutter mobile application before shifting toward a PWA to simplify distribution and provide access across supported devices.

The application is live and has received user registrations, although overall traffic and adoption remain limited.

## Key Features

- Role-based authentication, authorization, and onboarding.
- Separate dashboards for job seekers and hiring institutions.
- Job browsing, search, filtering, saving, and applications.
- Application tracking and invitations.
- Institution dashboards, grouped applicant lists, and candidate actions.
- Profile management and profile-completion indicators.
- Applicant document review and verification-related workflows.
- Conversations, messaging, unread badges, and support-conversation links.
- A notification interface with partially implemented functionality and feature-flag-controlled rollout.
