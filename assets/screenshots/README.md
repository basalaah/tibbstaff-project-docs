# Screenshots and Demonstrations

This directory contains selected screenshots of tibbstaff.com for portfolio and technical documentation purposes.

## Screenshot Guidelines

- Capture screenshots from the actual application.
- Use test accounts or sanitized data.
- Remove personal information, private messages, credentials, and confidential organizational details.
- Do not expose authentication tokens, API keys, private endpoints, or internal configuration.
- Use descriptive filenames.
- Keep screenshots representative of the current application.

## Suggested Screenshots

| Filename | What It Demonstrates |
|---|---|
| `job-seeker-dashboard.png` | Job seeker dashboard and summary cards |
| `job-search.png` | Job listings, search, and filtering |
| `job-application.png` | Job application workflow |
| `institution-dashboard.png` | Institution dashboard, profile completion, and status indicators |
| `applicants-by-job.png` | Applicants grouped by job and candidate actions |
| `messaging.png` | Messaging interface and conversation navigation |
| `notifications.png` | Notification interface, if suitable for public demonstration |
| `verification-review.png` | Document review and verification workflow, if safe and implemented |

Not every suggested screenshot needs to be included. Choose the clearest examples that demonstrate the implemented functionality.

## Embedding Screenshots in Markdown

From the root `README.md`, reference a screenshot using a relative path:

`![Job seeker dashboard](assets/screenshots/job-seeker-dashboard.png)`

From a file inside the `docs/` directory, use:

`![Job seeker dashboard](../assets/screenshots/job-seeker-dashboard.png)`

Add screenshots only after the image files have been uploaded to the corresponding directory.
